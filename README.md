# 👁️ Live Face Recognition Attendance System

## 🚀 Overview
This is an advanced, real-time Face Recognition Attendance System built with Python and Streamlit. It captures live video, detects and recognizes faces using OpenCV, logs attendance automatically, and sends instant email notifications to the recognized individuals.

## ✨ Key Features
* **Real-Time Face Recognition:** Uses OpenCV and `LBPHFaceRecognizer` for accurate face detection.
* **Instant Email Alerts:** Automatically sends a confirmation email to the student's registered ID as soon as their attendance is marked.
* **Automated Logging:** Saves attendance records securely in a CSV file and manages student data using an SQLite Database.
* **Secure Access:** Built-in login/authentication system to prevent unauthorized access to the dashboard.
* **Live Developer Metrics:** Displays "Raw Score" and "Match %" directly on the live camera feed for easy threshold tuning.
* **Modern UI/UX:** Premium styling with a dark-mode sidebar and custom CSS integrated into Streamlit.

## 🛠️ Technologies Used
* **Programming Language:** Python
* **Computer Vision:** OpenCV (Haar Cascades)
* **Web Framework:** Streamlit
* **Database:** SQLite3
* **Automation:** `smtplib` for email integrations
